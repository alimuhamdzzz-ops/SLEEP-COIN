# 3D Character Model

Place your 3D character model here as `sleeper.glb`.

## Model Requirements:
- **Format**: GLB or GLTF
- **Size**: Under 10MB
- **Character**: Female in sleeping/lying position
- **Clothing**: 
  - Orange/red plaid checkered shirt
  - Green pants with pattern
- **Hair**: Dark/black
- **Rigging**: Optional but recommended for better animation

## Where to Get Models:

### Option 1: Ready Player Me (Easiest)
1. Visit https://readyplayer.me/
2. Create a female avatar
3. Customize appearance to match reference
4. Download as GLB
5. Rename to `sleeper.glb`

### Option 2: Mixamo
1. Visit https://www.mixamo.com/
2. Browse female characters
3. Download in FBX format
4. Convert to GLB using https://gltf.report/
5. Rename to `sleeper.glb`

### Option 3: Sketchfab
1. Visit https://sketchfab.com/
2. Search for "sleeping character" or "female character"
3. Download free models with CC license
4. Place as `sleeper.glb`

## Note:
If no model is found, the application will create a simple placeholder character automatically.
The placeholder will still demonstrate the breathing animation.
